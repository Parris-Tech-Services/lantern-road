# Lantern Road — Core Quest Scene Pack

**Task:** LR-0047 — Author premium scene packs for the six core quests  
**Owner:** Agent 2 — The Storyteller  
**Status:** Authoring only. LR-0048 later integrates these scenes.

## Purpose

The six current quests already define the Grey March's local problems. This pack deepens them into authored stories with:

- distinctive offers;
- investigative or complication beats;
- meaningful resolution choices;
- deliberate refusal, delay, partial-success or failure material;
- consequence-aware aftermath;
- links to the LR-0043 campaign spine without forcing a main-quest order.

## Authoring rules

- Existing quest ids and canonical identities remain unchanged.
- Existing outcomes are preserved and deepened.
- New branch suggestions are declarative and belong to LR-0048 integration.
- Local quests remain independently satisfying even if the player ignores the regional campaign.
- Important NPC voices should agree with LR-0045 authoring, but these files own **quest-specific scenes**, not general recurring chatter.
- No `game.js`, `content.js`, save or condition-engine changes belong here.

## Shared scene structure

Each quest should provide:

1. **Offer** — why this person is asking and why it matters now.
2. **Complication/investigation** — something that changes the player's understanding.
3. **Decision/resolution** — a choice with actual trade-offs.
4. **Aftermath** — concrete human response.
5. **Non-ideal branch** — refusal, delay, failure or partial success that remains authored.
