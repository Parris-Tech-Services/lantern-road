# Director design reviews

Each merged approval record is named:

```

```

The approval commit must be the final feature-branch commit and may change only that review file. See `../DESIGN-REVIEW-PROTOCOL.md`.

These files are evidence that a specific code head was reviewed. They are not substitutes for Josh's final creative judgement.
